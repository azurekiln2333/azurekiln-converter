常见问题

 

问：OfflineConverter.com 是什么？

答：我们是 Aconvert.com （一个流行的在线文件转换网站）的所有者。 当我们在开发 Aconvert.com 的时候，我们注意到在线转换器的很多缺点，从而开始开发离线转换器。 得益于 ES 模块、WebAssembly、共享数组缓冲区和站点隔离等新技术，现在可以在网络浏览器中非常方便地直接离线转换文件。 我们在很多年前就开始开发 OfflineConverter.com 网站，但直到市场上绝大部分数浏览器都开始支持 WebAssembly 等技术后才发布。

问：为什么文件可以在网络浏览器中离线转换？

答：文件可以通过网络浏览器中的 JavaScript 或 WebAssembly 进行转换。 WebAssembly 是一种可以在现代网络浏览器中运行的代码类型 - 它是一种低级类汇编语言，具有紧凑的二进制格式，可以以接近本机的性能运行，并为 C/C++、C# 和 Rust 等语言提供 编译目标，以便它们可以在网络浏览器上运行。 它还被设计为与 JavaScript 一起运行，允许两者一起工作。

问：OfflineConverter.com 安全吗？

答：是的，OfflineConverter.com 可以安全使用。 离线转换器与在线转换器相反，它最大限度地保护您的隐私，因为所有文件都是在本地而不是云服务器上转换的， 您无需担心文件泄露。 我们使用的 WebAssembly 是一项安全的技术。 WebAssembly 运行在一种内存安全的沙盒执行环境，该环境甚至可以在现有 JavaScript 虚拟机内部实现。 当嵌入到网络浏览器中时，WebAssembly 将强制执行浏览器的同源和权限安全策略。

问：如何在 OfflineConverter.com 上转换文件？

答：在 OfflineConverter.com 上转换文件只需简单三步。

  • 1. 点击“选择文件”按钮选择本地设备上的本地文件。
  • 2. 选择目标格式并根据需要设置转换选项。
  • 3. 单击“离线转换”按钮并等待转换完成， 输出文件将在同一网页中列出。
问：OfflineConverter.com 支持哪些文件格式？

答：您可以在 https://offlineconverter.com/cn/format/ 查看支持的文件格式。 请注意，这只是 OfflineConverter.com 支持的一小部分文件格式，许多不流行的文件格式并未列出。 例如， OfflineConverter.com 支持大约 80 种图像格式，但仅列出了最流行的图像格式。 您可以直接在 OfflineConverter.com 上转换这些不流行的格式，没有任何问题。

问：为什么我无法在 OfflineConverter.com 上将 Word、Excel 或 PowerPoint 离线转换为 PDF？

答：要在网络浏览器中使用，转换器软件需要开源、体积小并且可以编译成 WebAssembly/Javascript。 我们使用 Microsoft Office 在 Aconvert.com 上在线转换 Word、Excel 和 PowerPoint 文件，Microsoft Office 是私有软件，体积大，且不能编译成 WebAssembly/Javascript。

问：OfflineConverter.com 支持哪些平台和网络浏览器？

答：您可以在任何已安装现代网络浏览器的操作系统（例如 Windows、Linux、Mac OS、Android 或 iOS）上使用 OfflineConverter.com。 网络浏览器可以是 Chrome 57+、Edge 16+、Firefox 52+、Safari 11+ 或 Opera 44+。 不支持所有版本的 Internet Explorer。

问：转换限制有哪些？

答：您每次可以选择不限数量的文件来转换，每个文件大小最大可达 2 GB，没有转换时间限制。

问：为什么第一次文件转换这么慢？

答：第一次文件转换前需要加载 Javascript。 对于视频和音频转换，加载的 JavaScript 最大可达 32mb。 如果网络连接速度较慢，可能需要一段时间才能从服务器下载完 Javascript。

问：为什么转换速度比桌面软件慢？

答：到目前为止，WebAssembly/Javascript 仍然比原生慢很多。 新的 WebAssembly intrinsic 技术可能会提高速度，因为 WebAssembly intrinsic 基本上就是编译成汇编代码， 这是我们正在研究并希望将来推出的东西。 导致转换缓慢的另一个原因是 OfflineConverter.com 默认使用单线程。 使用多线程可能会消耗大量的内存或CPU，并且需要额外的安全措施，例如共享数组缓冲区和站点隔离。

问：为什么我的转换失败？

答：大多数转换失败是由不兼容的网络浏览器或操作系统引起的。 我们建议升级到最新版本的操作系统和网络浏览器。 还有许多其他原因可能导致转换失败，例如：源文件格式不支持、已损坏、使用密码或数字版权管理 (DRM) 加密。 如果此离线转换器无法在您的网络浏览器中运行，请尝试在线转换器。

问：如何将所有输出文件保存在一个 ZIP 文件中？

答：要将所有输出文件保存在一个 ZIP 文件中，只需单击“输出文件”区域里的“压缩文件”按钮即可。

问：如何删除所有输出文件？

答：要删除所有输出文件，只需关闭网络浏览器中的网页即可。 所有输出文件将立即被清除并且无法恢复。

问：离线转换器还是在线转换器，我应该选择哪一个？

答：OfflineConverter.com 是一个离线转换器，因此我们推荐离线转换器:) 您可以在索引页查看离线转换器和在线转换器的详细比较，并选择合适您的转换器。
