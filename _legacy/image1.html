Cómo usar

Elija archivos de imagen locales, elija el formato de imagen de destino al que desea convertir, luego haga clic en el botón "CONVERTIR SIN CONEXIÓN" para iniciar conversiones sin conexión en masa. Cada archivo puede tener hasta 2 GB.

Este convertidor fuera de línea intentará usar el lienzo en el navegador web para convertir imágenes primero. El formato de la imagen depende de si su navegador web actual lo admite. Por ejemplo: el último navegador Chrome admite imágenes AVIF, mientras que la versión anterior no lo hace. Luego, el convertidor fuera de línea intentará usar JavaScript para convertir imágenes si su navegador web actual no es compatible con el formato de imagen. Utilice el conversor en línea en su lugar si este conversor fuera de línea no funciona en su navegador web.
