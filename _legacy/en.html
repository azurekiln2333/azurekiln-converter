在您的网络浏览器中直接使用 JavaScript 离线转换图片、视频、音频和文档文件，无需下载软件和上传文件！ 离线转换器与在线转换器相反，它是为了最大限度地保护您的隐私，因为所有文件都是在本地转换而不是云服务器。 离线转换器的另一个优点是每个文件大小可以达到 2GB，而很少有在线转换器支持大于 100MB 的文件。

Offline Converter

Convert image, video, audio and document files offline by JavaScript in your web browser without any software downloads or file uploads! Offline converter is the opposite of online converter, it's for maximum protection of your privacy because all files are converted locally instead of cloud servers. Another advantage of offline converter is that file size can be up to 2 GB while very few online converters support file size larger than 100 MB.

Please note some web browsers do not support or do not fully support offline converter yet. We recommend using the latest Chrome browser for Windows. Try online converter instead if this offline converter doesn't work in your web browser.
