Como usar

Escolha arquivos de áudio ou vídeo locais, escolha o formato de áudio de destino para o qual deseja converter e clique no botão "CONVERTER OFFLINE" para iniciar conversões offline em massa. Cada arquivo pode ter até 2 GB.

Observe que este conversor de áudio offline só funciona em navegadores da Web que suportam novas tecnologias, como WebAssembly, Shared Array Buffer e Site Isolation. Use conversor online se este conversor offline não funcionar em seu navegador da web.
