Introduction The only difference between the JPG and JPEG formats is the number of characters used. JPG only exists because in earlier versions of Windows they required a three letter extension for the file names. So .jpeg was shortened to .jpg. While Windows and or DOS had this limitation, UNIX did not and so UNIX and MAC users continued to use the .jpeg extension.
