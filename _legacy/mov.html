Introduction QuickTime File Format (QTFF) is a computer file format used natively by the QuickTime framework. The International Organization for Standardization approved the QuickTime file format as the basis of the MPEG-4 file format. Because both the QuickTime and MP4 container formats can use the same MPEG-4 formats, they are mostly interchangeable in a QuickTime-only environment.
