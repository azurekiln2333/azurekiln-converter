How to use

Choose local video, audio or image files, then click the "GET FILE INFORMATION" button to get detailed media information. Detailed information includes:

General: Format, Codec, File size, Writing application, etc.
Video: Format, Codec, Duration, Bit rate, Width, Height, Display aspect ratio, Frame rate, Color space, Bit depth, Stream size, etc.
Audio: Format, Codec, Duration, Bit rate, Channel, Frame rate, Sampling rate, Compression mode, Stream size, etc.
Image: Format, Width, Height, Color space, Chroma subsampling, Bit depth, Compression mode, Stream size, etc.

If the offline file analyzer doesn't work in your web browser, consider using online file analyzer instead.
