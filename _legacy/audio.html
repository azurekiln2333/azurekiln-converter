How to use

Choose local video or audio files, choose target audio format you want to convert to, then click the "CONVERT OFFLINE" button to start offline conversions in bulk. Each file can be up to 2GB.

Please note this offline audio converter only works in web browsers that support new technologies such as WebAssembly, Shared Array Buffer and Site Isolation. Use online converter instead if this offline converter doesn't work in your web browser.
