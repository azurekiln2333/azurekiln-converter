How to use

Choose local video files. Set percentage of video bitrate. Valid range is 1 to 100, higher numbers indicating higher bitrate and bigger output file size. For example: if the bitrate of input video is 420 kb, then the bitrate of output video will be 252 (420 * 60%) kb if the value is set to 60. The audio streams in video files are not compressed by default, you can compress audio by selecting the "Compress audio with same compression ratio" option. Finally click the "COMPRESS" button to start processing.

If the offline video compressor doesn't work in your web browser, consider using online video compressor instead.
