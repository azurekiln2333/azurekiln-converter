Developed by Microsoft & IBM
Type of format Audio file format, container format
Associated programs ALLPlayer, VLC media player, Media Player Classic, MPlayer, RealPlayer, Winamp.
Introduction Waveform Audio File Format is a Microsoft and IBM audio file format standard for storing an audio bitstream on PCs. It is the main format used on Windows systems for raw and typically uncompressed audio. The usual bitstream encoding is the linear pulse-code modulation (LPCM) format.
