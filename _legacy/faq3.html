よくある質問

 

Q: OfflineConverter.com とは何ですか?

A: 私たちは、Aconvert.com (人気のあるオンライン ファイル変換 Web サイト) の所有者です。 Aconvert.com を開発していたとき、オンライン コンバーターの多くの欠点に気づき、オフライン コンバーターの開発を開始しました。 ES モジュール、WebAssembly、共有配列バッファ、サイト分離などの新しいテクノロジのおかげで、Web ブラウザで直接オフラインでファイルを変換することが非常に便利になりました。 私たちは何年も前に OfflineConverter.com Web サイトの開発を開始しましたが、市場に出回っているブラウザの大部分が WebAssembly などのテクノロジをサポートし始めるまで立ち上げませんでした。

Q: Web ブラウザでファイルをオフラインで変換できるのはなぜですか?

A: ファイルは、Web ブラウザの Javascript または WebAssembly 経由で変換できます。 WebAssembly は、最新の Web ブラウザで実行できるコードの一種です。これは、ネイティブに近いパフォーマンスで実行できるコンパクトなバイナリ形式を備えた低レベルのアセンブリのような言語であり、C/C++、C#、および Rust 用に構築されています。言語は、Web ブラウザ上で実行できるようにコンパイル ターゲットを提供します。 また、JavaScript で実行できるように設計されており、両者を連携させることができます。

Q: OfflineConverter.com は安全ですか?

A: はい、OfflineConverter.com は安全に使用できます。 オフラインコンバーターはオンラインコンバーターとは逆で、すべてのファイルがクラウドサーバーではなくローカルで変換されるため、プライバシーを最大限に保護し、ファイル漏洩を心配する必要はありません。 私たちが使用する WebAssembly は安全なテクノロジーです。 WebAssembly は、既存の Javascript 仮想マシン内に実装することもできる、メモリ安全なサンドボックス実行環境で実行されます。 WebAssembly を Web ブラウザーに埋め込むと、ブラウザーの同一オリジンおよびアクセス許可のセキュリティ ポリシーが適用されます。

Q: OfflineConverter.com でファイルを変換するにはどうすればよいですか?

A: OfflineConverter.com でファイルを変換するには、3 つの簡単な手順を実行するだけです。

  • 1. [ファイルの選択] ボタンをクリックして、ローカル デバイス上のローカル ファイルを選択します。
  • 2. ターゲット形式を選択し、必要に応じて変換オプションを設定します。
  • 3. [オフライン変換] ボタンをクリックし、変換が完了するまで待ちます。出力ファイルが同じ Web ページにリストされます。
Q: OfflineConverter.com はどのようなファイル形式をサポートしていますか?

A: サポートされているファイル形式は、https://offlineconverter.com/jp/format/ で確認できます。 これは OfflineConverter.com でサポートされているファイル形式のほんの一部であり、あまり一般的ではないファイル形式の多くはリストされていないことに注意してください。 たとえば、OfflineConverter.com は約 80 の画像形式をサポートしていますが、リストされているのは最も一般的なものだけです。 これらの不人気な形式は、OfflineConverter.com で問題なく直接変換できます。

Q: OfflineConverter.com で Word、Excel、PowerPoint をオフラインで PDF に変換できないのはなぜですか?

A: Web ブラウザで使用するには、コンバータ ソフトウェアがオープンソースで小規模であり、WebAssembly/JavaScript にコンパイルされる必要があります。 Aconvert.com では、Microsoft Office を使用して Word、Excel、PowerPoint のファイルをオンラインで変換しています。Microsoft Office は独自のソフトウェアであり、大規模な機能を備えています。また、WebAssembly/JavaScript にコンパイルすることはできません。

Q: OfflineConverter.com はどのようなプラットフォームと Web ブラウザをサポートしていますか?

A: OfflineConverter.com は、Windows、Linux、Mac OS、Android、iOS など、最新の Web ブラウザがインストールされているオペレーティング システムで使用できます。 Web ブラウザには、Chrome 57 以降、Edge 16 以降、Firefox 52 以降、Safari 11 以降、または Opera 44 以降を使用できます。 Internet Explorer のすべてのバージョンがサポートされているわけではありません。

Q: 変換に関する制限は何ですか?

A: 一度に変換するファイルの数に制限はなく、各ファイルのサイズは最大 2 GB まで、変換時間の制限はありません。

Q: 最初のファイル変換が非常に遅いのはなぜですか?

A: 最初のファイル変換の前に Javascript をロードする必要があります。 ビデオとオーディオの変換の場合、ロードされる Javascript は最大 32MB になる可能性があります。 ネットワーク接続が遅い場合、JavaScript がサーバーからダウンロードされるのに時間がかかることがあります。

Q: 変換速度がデスクトップ ソフトウェアより遅いのはなぜですか?

A: 今のところ、WebAssembly/JavaScript はネイティブよりもまだかなり遅いです。 WebAssembly 組み込みは基本的にアセンブリ コードにコンパイルされるため、新しい WebAssembly 組み込みテクノロジにより速度が向上する可能性があります。これは現在開発中であり、将来リリースされる予定です。 変換が遅いもう 1 つの理由は、OfflineConverter.com がデフォルトでシングル スレッドを使用していることです。 マルチスレッドを使用すると、大量のメモリまたは CPU が消費される可能性があり、共有アレイ バッファやサイト分離などの追加の安全対策が必要になります。

Q: 変換が失敗したのはなぜですか?

A: 変換エラーのほとんどは、互換性のない Web ブラウザまたはオペレーティング システムが原因で発生します。 オペレーティング システムと Web ブラウザーの最新バージョンにアップグレードすることをお勧めします。 変換が失敗する理由は他にも多数あります。たとえば、ソース ファイル形式がサポートされていない、破損している、パスワードまたはデジタル著作権管理 (DRM) で暗号化されているなどです。 このオフライン コンバーターが Web ブラウザで動作しない場合は、オンライン コンバーターをお試しください。

Q: すべての出力ファイルを 1 つの ZIP ファイルに保存するにはどうすればよいですか?

A: すべての出力ファイルを ZIP ファイルに保存するには、[出力ファイル] 領域の [Zip ファイル] ボタンをクリックするだけです。

Q: すべての出力ファイルを削除するにはどうすればよいですか?

A: すべての出力ファイルを削除するには、Web ブラウザのページを閉じるだけです。 すべての出力ファイルはすぐに消去され、復元できなくなります。

Q: オフライン コンバーターとオンライン コンバーター、どちらを選択すればよいですか?

A: OfflineConverter.com はオフライン コンバーターであるため、オフライン コンバーターをお勧めします:) インデックス ページ でオフライン コンバーターとオンライン コンバーターを確認できます。詳細を比較してください。自分に合ったコンバータを選択してください。

Q: さらに質問があるのですが、誰にメールすればよいですか?

A: その他のご質問は、support@aconvert.com までお送りください。ファイル変換に関するものであれば、通常 1 営業日以内に返信が届きます。その他の質問は無視される場合があります。
