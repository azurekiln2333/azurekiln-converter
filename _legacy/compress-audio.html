How to use

Choose local audio files. Set percentage of audio bitrate. Valid range is 1 to 100, higher numbers indicating higher bitrate and bigger output file size. For example: if the bitrate of input audio is 420 kb, then the bitrate of output audio will be 252 (420 * 60%) kb if the value is set to 60. Decreasing bitrate won't work on lossless audio formats such as WAVE, FLAC or AIFF. We use an alternative compression algorithm for these formats. Finally click the "COMPRESS" button to start processing.

If the offline audio compressor doesn't work in your web browser, consider using online audio compressor instead.
