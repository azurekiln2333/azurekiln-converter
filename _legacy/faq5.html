常見問題

 

問：OfflineConverter.com 是什麼？

答：我們是 Aconvert.com （一個受歡迎的線上文件轉換網站）的所有者。 當我們在開發 Aconvert.com 的時候，我們注意到線上轉換器的許多缺點，從而開始開發離線轉換器。 由於 ES 模組、WebAssembly、共享數組緩衝區和網站隔離等新技術，現在可以在網頁瀏覽器中非常方便地直接離線轉換檔案。 我們在很多年前就開始開發 OfflineConverter.com 網站，但直到市場上絕大部分數瀏覽器都開始支援 WebAssembly 等技術後才發布。

問：為什麼檔案可以在網頁瀏覽器中離線轉換？

答：檔案可以透過網頁瀏覽器中的 JavaScript 或 WebAssembly 轉換。 WebAssembly 是一種可以在現代網頁瀏覽器中運行的程式碼類型- 它是一種低階類別彙編語言，具有緊湊的二進位格式，可以以接近本機的效能運行，並為C/C++、C# 和Rust 等 語言提供編譯目標，以便它們可以在網頁瀏覽器上運行。 它也被設計為與 JavaScript 一起運行，允許兩者一起工作。

問：OfflineConverter.com 安全嗎？

答：是的，OfflineConverter.com 可以安全使用。 離線轉換器與線上轉換器相反，它最大限度地保護您的隱私，因為所有文件都是在本地而不是雲端伺服器上轉換的， 您無需擔心文件外洩。 我們使用的 WebAssembly 是一項安全的技術。 WebAssembly 運行在一個記憶體安全的沙盒執行環境，該環境甚至可以在現有 JavaScript 虛擬機器內部實現。 當嵌入到網頁瀏覽器中時，WebAssembly 將強制執行瀏覽器的同源和權限安全性策略。

問：如何在 OfflineConverter.com 上轉換檔案？

答：在 OfflineConverter.com 上轉換檔案只需簡單三步驟。

  • 1. 點選「選擇檔案」按鈕選擇本機裝置上的本機檔案。
  • 2. 選擇目標格式並依需求設定轉換選項。
  • 3. 點選「離線轉換」按鈕並等待轉換完成， 輸出檔案將會在同一網頁中列出。
問：OfflineConverter.com 支援哪些文件格式？

答：您可以在 https://offlineconverter.com/tw/format/ 查看支援的檔案格式。 請注意，這只是 OfflineConverter.com 支援的一小部分文件格式，許多不流行的文件格式並未列出。 例如， OfflineConverter.com 支援大約 80 種圖像格式，但僅列出了最受歡迎的圖像格式。 您可以直接在 OfflineConverter.com 上轉換這些不流行的格式，沒有任何問題。

問：為什麼我無法在 OfflineConverter.com 上將 Word、Excel 或 PowerPoint 離線轉換為 PDF？

答：要在網頁瀏覽器中使用，轉換器軟體需要開源、體積小並且可以編譯成 WebAssembly/Javascript。 我們使用Microsoft Office 在Aconvert.com 上在線轉換Word、Excel 和PowerPoint 文件，Microsoft Office 是私有軟體，體積大， 且不能編譯成WebAssembly/Javascript。

問：OfflineConverter.com 支援哪些平台和網頁瀏覽器？

答：您可以在任何已安裝現代網頁瀏覽器的作業系統（例如 Windows、Linux、Mac OS、Android 或 iOS）上使用 OfflineConverter.com。 網路瀏覽器可以是 Chrome 57+、Edge 16+、Firefox 52+、Safari 11+ 或 Opera 44+。 不支援所有版本的 Internet Explorer。

問：轉換限制有哪些？

答：您每次可以選擇不限數量的檔案來轉換，每個檔案大小最大可達 2 GB，沒有轉換時間限制。

問：為什麼第一次檔案轉換這麼慢？

答：第一次檔案轉換前需要載入 Javascript。 對於視訊和音訊轉換，已載入的 JavaScript 最大可達 32mb。 如果網路連線速度較慢，可能需要一段時間才能從伺服器下載 Javascript。

問：為什麼轉換速度比桌面軟體慢？

答：到目前為止，WebAssembly/Javascript 仍然比原生慢很多。 新的 WebAssembly intrinsic 技術可能會提高速度，因為 WebAssembly intrinsic 基本上就是編譯成彙編程式碼， 這是我們正在研究並希望將來推出的東西。 導致轉換緩慢的另一個原因是 OfflineConverter.com 預設使用單線程。 使用多執行緒可能會消耗大量的記憶體或CPU，並且需要額外的安全措施，例如共享陣列緩衝區和網站隔離。

問：為什麼我的轉換失敗？

答：大多數的轉換失敗是由不相容的網頁瀏覽器或作業系統引起。 我們建議升級到最新版本的作業系統和網頁瀏覽器。 還有許多其他原因可能導致轉換失敗，例如：原始檔案格式不支援、已損壞、使用密碼或數位版權管理 (DRM) 加密。 如果此離線轉換器無法在您的網頁瀏覽器中運行，請嘗試線上轉換器。

問：如何將所有輸出檔案保存在一個 ZIP 檔案中？

答：要將所有輸出檔案儲存在一個 ZIP 檔案中，只需點選「輸出檔案」區域裡的「壓縮檔案」按鈕即可。

問：如何刪除所有輸出檔？

答：要刪除所有輸出文件，只需關閉網頁瀏覽器中的網頁即可。 所有輸出檔案將立即被清除並且無法恢復。

問：離線轉換器還是線上轉換器，我該選擇哪一個？

答案：OfflineConverter.com 是一個離線轉換器，因此我們推薦離線轉換器:) 您可以在索引頁查看離線轉換器和線上轉換器的 詳細比較，並選擇合適您的轉換器。
